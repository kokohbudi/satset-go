SEO fundamentals including E-E-A-T framework, Core Web Vitals, technical SEO, content SEO, schema markup, and AI content guidelines.

## Behavior

When `/seo-fundamentals` is triggered:

1. **Understand context**
   - What type of site/page?
   - Current SEO status?
   - Target audience?

2. **Apply frameworks**
   - E-E-A-T (Experience, Expertise, Authoritativeness, Trustworthiness)
   - Core Web Vitals
   - Technical SEO principles
   - Content SEO principles

3. **Implement**
   - Schema markup types
   - Meta tags and structure
   - AI content guidelines
   - Ranking factors (prioritized)

4. **Validate**
   - Run `.agent/skills/seo-fundamentals/scripts/seo_checker.py` if applicable
